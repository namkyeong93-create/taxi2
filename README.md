# 천안시 교통정책 웹 프레젠테이션

첨부된 **천안시 교통정책** 원본 PPTX 10장을 기준으로 제작한 정적 웹사이트입니다. (요청 문구의 청년정책과 첨부 파일의 교통정책은 서로 다릅니다.)

## 열기

`index.html`을 웹브라우저로 열면 바로 작동합니다. 별도 서버, 설치, API 키, 데이터베이스가 필요하지 않습니다.

## GitHub Pages 게시

1. 새 GitHub 저장소를 만들고, 이 ZIP의 **내용물 전체**(`index.html`, `assets/`, `slides.json`, `README.md`)를 저장소 최상위에 업로드합니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`를 선택합니다.
3. Branch `main`, Folder `/(root)`를 선택하고 저장합니다.
4. GitHub Pages가 제공하는 주소에서 웹사이트를 엽니다.

## 기능

- 원본 슬라이드를 이미지화하여 색상·레이아웃·삽입 그림을 최대한 보존
- 상단 목차 버튼(10장 썸네일), 이전·다음 버튼, 진행 표시, 슬라이드 번호
- 키보드 방향키 / PageUp / PageDown / Home / End / 마우스 휠 / 모바일 스와이프
- 화면 전환 애니메이션, 전체화면(F), 원본 텍스트 보기
- 반응형, 외부 CDN 미사용, 상대 경로만 사용, 모션 축소 환경 지원
- `#slide-4` 같은 주소로 개별 슬라이드 직접 연결

## 편집 안내

슬라이드 시각 요소는 웹용 이미지(`assets/slides/*.webp`)로 저장되어 있으므로, 개별 도형이나 차트 데이터는 웹페이지에서 별도로 편집되지 않습니다. 원본 슬라이드 텍스트는 `slides.json`에 보존되어 있으며 사이트의 **내용 보기** 패널에도 노출됩니다.

원본에 없는 수치나 정책 내용은 추가하지 않았습니다.
